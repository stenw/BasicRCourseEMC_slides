If? Then! Else?

Conditional execution:

if (condition) {
  statement1
}

or

if (condition) {
  statement1
} else {
  statement2
}

Example

x <- 5
if (x < 10) {
  y <- 0
}
y
[1] 0

Another example:

if (x >= 10) {
  y <- 1
} else {
  y <- 0
}
y
[1] 0

If else on one line

Oneliner:

y <- if(x >= 10) 1 else 0
y
[1] 0

With x = 5, the condition is false. Without an else branch, the expression returns NULL, which is assigned to y.

y <- if (x >= 10) 1
y
NULL

Nested if() Statements

if inside an if

if(condition1) {
  if(condition2) {
    statement1 
  } else {
    statement2
  }
}

Stringing multiple if else together

whatAnimalSound <- function(animal){
  if(animal == "cat") {
    return("Meow!")
  } else if (animal == "frog") {
    return("Ribbit!")
  } else if (animal == "dog") {
    return("Woof!")
  } else {
    return(paste0("I don't know what sound a '",animal,"' makes..."))
  }
}
whatAnimalSound("dog")
[1] "Woof!"
whatAnimalSound("bird")
[1] "I don't know what sound a 'bird' makes..."

Terminating a function with returns, errors, and warnings

The following functions are useful for terminating a function call or just printing a warning message:

return()     # Terminate a function call and return a value
stop()       # Terminate a function call and print an error message
warning()    # Print a warning message (without terminating the function call)

Terminating a Function Call Using return()

mySign <- function(x) {
  if(x < 0) return("Negative")
  if(x > 0) return("Positive")
  return("Zero")
}

mySign(x = 13)
[1] "Positive"

Note: return("Zero") not reached

Terminating Using stop()

Start with two single numbers. If the denominator is zero, stop() ends the call before division.

myRatio <- function(x, y) {
  if (y == 0) stop("Cannot divide by zero")
  x / y
}
myRatio(3, 2)
[1] 1.5
myRatio(3, 0)
Error in `myRatio()`:
! Cannot divide by zero

Printing a Warning Message Using warning()

warning() reports a problem and lets the function continue.

myRatioWarn <- function(x, y) {
  if (y == 0) warning("Dividing by zero")
  x / y
}

myRatioWarn(3, 0)
[1] Inf

The function reaches x / y and returns Inf.

Validate the denominator

Before checking for zero, verify that the denominator is one nonmissing number.

myRatioChecked <- function(x, y) {
  if (!is.numeric(y)) stop("y must be numeric")
  if (length(y) != 1) stop("y must have one value")
  if (is.na(y)) stop("y must not be missing")
  myRatio(x, y)
}

Decide which inputs to accept

Accept numeric ages. Remove missing values, then keep ages strictly above zero.

my_descriptives <- function(x) {
  if (!is.numeric(x)) stop("Expected numeric ages")
  ages <- x[!is.na(x)]
  ages <- ages[ages > 0]
  if (length(ages) == 0) stop("No positive ages left")
  summary(ages)
}

Looping

Repeat (iterate) an R statement

for() # Repeat a set of statements a specified number of times
while() # Repeat a set of statements as long as a specified condition is met
repeat # Repeat a set of statements until a break command is encountered

Stopping a loop:

break # Terminate a loops iterations
next # Skip ahead to the next iteration

Why colMeans(coins) fails

colMeans(coins)
Error in `colMeans()`:
! 'x' must be numeric or complex

colMeans() converts the data frame to a matrix. A matrix has one type, so the text columns cause the numbers to become text too. Select the numeric columns before taking means.

Using apply functions

The apply family runs a function such as mean() repeatedly over parts of your data, without writing a loop yourself.

  • apply() works across rows or columns of a matrix.
  • lapply() works on each list element and returns a list.
  • sapply() does the same and combines results into a vector or matrix when possible.
  • tapply() works on groups of values.

Using apply on matrices

apply() requires 3 arguments:

args(apply)
function (X, MARGIN, FUN, ..., simplify = TRUE) 
NULL
  • x: the data
  • MARGIN: 1, 2, or c(1,2)
  • function: the function to apply (without the ( ))

What sapply() returns

A vector when each column gives one sum.

sapply(df, sum)
col1 col2 col3 
   4    8   12

A matrix when each input matrix gives two dimensions. Each result becomes a column.

sapply(mylist, dim)
     [,1] [,2] [,3]
[1,]    4    3    2
[2,]    4    3    2

If the results have different lengths, sapply() keeps them in a list.

Column means with sapply()

Select the numeric columns, then apply mean() to each one. This gives the same named results as the loop.

numeric_columns <- sapply(coins, is.numeric)
sapply(coins[numeric_columns], mean)
